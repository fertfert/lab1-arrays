# Лабораторная работа №1. Массивы

Реализация статического и динамического массивов на Python 3.10+ по слайдам и раздаточным материалам «Алгоритмы и структуры данных». Выполнены бронзовый, серебряный и золотой уровни.

## Запуск

```bash
python demo.py
python -m unittest discover -s tests -v
python -m pip install -r requirements.txt
python benchmark.py
```

Для структур данных и тестов достаточно стандартной библиотеки. Matplotlib нужен только для повторного построения графиков. Готовые результаты находятся в `results/`, выводы — в [REPORT.md](REPORT.md).

## Файлы и требования

| Уровень | Файл | Реализовано |
|---|---|---|
| Бронза | `static_array.py` | `StaticArray`: get, set, append, len, str; контроль переполнения |
| Серебро | `dynamic_array.py` | `DynamicArray`: append, get, set, insert, remove, find, binary_search; рост и сжатие |
| Золото | `dynamic_array_gold.py` | `DynamicArrayGold`: коэффициент роста; 100 000 добавлений для 2.0 и 1.5 |
| Эксперименты | `benchmark.py` | Замеры, исходные CSV, графики роста и поиска |
| Проверка | `tests/test_arrays.py` | Пример из раздатки, границы, поиск, рост, сжатие, случайные последовательности |

Хранилище — `(ctypes.py_object * capacity)()`. Встроенные `list`, `dict`, `set` не используются как реализация массивов. В тестах `list` служит эталоном сравнения, в экспериментах контейнеры хранят результаты замеров.

## Контракт методов

- Индексы начинаются с нуля. Отрицательные индексы и выход за размер вызывают `IndexError`; нецелый индекс вызывает `TypeError`.
- `insert(len(array), value)` вставляет в конец. `set` меняет только существующий элемент.
- `remove(index)` удаляет по индексу, возвращает `None`. `find(value)` возвращает первый индекс или `None`.
- `binary_search` требует заранее отсортированных по возрастанию сопоставимых значений. При дубликатах возвращает один подходящий индекс. Проверка сортировки не выполняется, поскольку заняла бы O(n).
- `capacity` — ёмкость, `len` — число элементов. Строка пустого массива: `[]`.
- `DynamicArray` удваивает ёмкость. При заполнении не более четверти после удаления ёмкость уменьшается вдвое, минимум до 1.
- В золотом уровне используется формула раздатки `int(capacity * factor) + 1`, поэтому при factor=2 последовательность равна 1, 3, 7, 15, …, а не 1, 2, 4, 8. Рост применяется как к `append`, так и к `insert`; сжатие остаётся вдвое.

## Сложность

| Операция | StaticArray | DynamicArray |
|---|---|---|
| get / set / len | O(1) | O(1) |
| append | O(1), если есть место | O(1) амортизированно; O(n) при росте |
| insert в начало / середину | Не реализована | O(n) |
| remove в начале / середине | Не реализована | O(n) |
| remove в конце | Не реализована | O(1) амортизированно; O(n) при сжатии |
| find | Не реализована | O(n) |
| binary_search | Не реализована | O(log n) |
| str | O(n) | O(n) |

Память массива пропорциональна ёмкости и хранит ссылки на Python-объекты. При перевыделении временно существуют старый и новый буферы. Сумма копирований при геометрическом росте — O(n), поэтому n последовательных добавлений занимают O(n).
